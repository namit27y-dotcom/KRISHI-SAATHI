🌾 Krishi Saathi

A Digital Agriculture Marketplace Connecting Farmers with
Agricultural Products and Suppliers

Krishi Saathi is a modern agriculture marketplace designed to help
farmers and agricultural buyers discover agricultural products and
connect with suppliers through a simple, accessible, and user-friendly
platform.

The marketplace brings products such as seeds, fertilizers,
pesticides, tractors, water pumps, sprayers, irrigation equipment, and
farm tools into one digital platform.

🚀 Live Demo

Website: https://krishi-saathi-three.vercel.app/

📌 Problem Statement

Farmers often need to search across multiple local shops and suppliers
to find agricultural products, compare prices, and identify suitable
farming equipment.

Common challenges include:

Limited product discovery

Difficulty comparing products and prices

Dependence on local availability

Lack of centralized product information

Limited digital access to agricultural suppliers

Difficulty finding specialized farming equipment

Krishi Saathi aims to provide a centralized digital marketplace
where agricultural products can be discovered more conveniently.

💡 Solution

Krishi Saathi provides an online marketplace where users can:

Browse agricultural products

Search for products

Filter products by category

View product details

Compare available products

Check prices and ratings

Add products to a cart

Explore agricultural equipment

Connect with agricultural suppliers

The platform focuses on a clean, responsive, agriculture-oriented user
experience for desktop and mobile users.

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/krishi-saathi.git

2. Navigate to the project

cd krishi-saathi

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will normally be available at:

http://localhost:5173

🔐 Environment Variables

If the project uses APIs or external services, create a .env file.

Example:

VITE_API_URL=your_api_url
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key

Never commit private API keys or secrets to GitHub.

Add environment files to .gitignore:

.env
.env.local
